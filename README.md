# AI Support Ticket Analyzer

An AI-powered support ticket analytics system that converts natural-language questions into structured queries and analyzes support ticket data using Python, Pandas, and Gemini.

## Features

- Natural-language ticket queries using Gemini LLM
- Ticket filtering and aggregation
- Average, sum, min, max, and count analysis
- Group-wise ticket analysis
- Resolution-time anomaly detection
- Critical unresolved ticket detection
- FastAPI REST API
- Simple web UI
- Unit tests with Pytest

## Tech Stack

- Python
- FastAPI
- Pandas
- Google Gemini API
- HTML/CSS/JavaScript
- Pytest
